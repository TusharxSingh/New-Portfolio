# Tushar Singh Chauhan - Portfolio

A modern, fast, and visually stunning portfolio website showcasing projects, experience, and expertise. Built with cutting-edge web technologies and best practices.

## 🚀 Features

- **Modern Design**: Clean, minimalist interface with smooth interactions
- **Dark & Light Mode**: Seamless theme switching
- **Smooth Animations**: Fluid page transitions and scroll effects
- **Responsive Design**: Works beautifully on all devices
- **Fast Performance**: Optimized for speed and user experience
- **Type Safe**: Built with TypeScript

## 📋 Pages

- **Home** (`/`) — Hero, about preview, experience timeline, projects showcase, contact form
- **About** (`/about`) — Full developer story with animations
- **Projects** (`/projects`) — Interactive project showcase
- **Contact** — Get in touch with form and social links

## 🛠️ Tech Stack

- Next.js 16
- React & TypeScript
- Tailwind CSS
- Framer Motion
- GSAP
- Modern animations & effects

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
